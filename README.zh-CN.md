# Photo Particles

[English](README.md) | **简体中文**

Minecraft Fabric 模组，给游戏加两种方块：照片方块和视频方块。右键方块打开游戏内的文件浏览器，选一张图或一个 GIF，它会在方块上方显示成一张背光的平面图。

图片走的是方块实体的动态贴图渲染，不是粒子拼的，所以边缘是干净的，也不会一行行扫。

## 两个方块

**照片方块**：右键选图片，支持 png、jpg、jpeg、bmp、gif。解析时按最长边缩放到最多 384 像素，画面上每格对应 144 像素，缩放用最近邻，保持像素锐利。

**视频方块**：右键选 GIF 或 MP4，循环播放。文件在客户端解析成最多 40 帧、最长边 192 像素的画面，再上传到服务器存进方块，服务器上所有玩家都能看到播放。解析在后台线程进行并显示进度，期间可以关掉方块界面去干别的。

两个方块都是自发光渲染，暗处、夜里、地下都不会变暗。显示时的朝向由你放置时面对的方向决定。

## 版本要求

- Minecraft 26.2
- Fabric Loader 0.19.5 及以上
- Fabric API
- Java 25

## 安装

把构建产物 `build/libs/photoparticles-0.3.0.jar` 放进 `.minecraft/mods` 就行，Fabric API 也要在里面。

## 自己构建

```
gradlew build
```

Windows 下需要 JDK 25。产物不带 remap，直接丢进 Fabric 就能跑。

## 已知限制

- 视频只支持 GIF 和 MP4。MP4 用纯 Java 的 JCodec 解码，认 H.264，其它编码不支持。
- 解析后的视频数据必须小于 8 MB，因为它要上传到服务器并随存档保存。过长或过大的片段会先抽帧压到 40 帧以内。
- 照片的像素数据存在方块实体里并随存档保存，一张图最多 384×384，放太多会占存档体积。
- 缺少 `java.desktop` 的运行环境（例如 FCL 这类安卓启动器）无法解码图片。模组会检测到并退回到只显示方块模型，不会崩溃，但也显示不出图片。
